* 总体安排

计划周期：12 周。

主线：
- 每周以 CS3110 为主教材。
- 每周配合 LPO 中相近主题做程序实践。
- 每周至少完成一个小产出：代码、笔记、对比总结或测试。

学习节奏建议：
- 每周 4 天学习，每天 1.5 到 2 小时。
- 每周 1 天整理笔记。
- 每周 1 天写小程序或补测试。
- 每周允许 1 天缓冲。

每周固定动作：
1. 阅读 CS3110 对应章节。
2. 阅读 LPO 对应小节。
3. 在 utop 中手敲关键代码。
4. 用 dune 建一个小练习。
5. 写一页 org 总结。
6. 提炼“这和 Python / Java / Lisp / Nix 有什么关系”。
