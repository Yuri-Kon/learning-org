* 总体安排

计划周期：12 周。

核心定位：
- OCaml 是主要学习对象，用来系统理解函数式编程、类型系统、模块系统、递归、代数数据类型、程序正确性与解释器。
- Nix 是环境提供者和辅助学习对象，用来管理 OCaml 学习环境，同时作为函数式配置语言帮助理解声明式依赖、纯函数式表达、惰性求值与可复现性。
- 学习顺序上，不需要先学完 Nix 再学 OCaml；本计划采用“用 Nix 提供环境，在必要时逐步理解 Nix”的方式。

主线资料：
- CS3110 Textbook: [[https://cs3110.github.io/textbook/cover.html][OCaml Programming: Correct + Efficient + Beautiful]]
- CS3110 Install Page: [[https://cs3110.github.io/textbook/chapters/preface/install.html][Installing OCaml]]
- Learn Programming with OCaml: [[https://usr.lmf.cnrs.fr/lpo/][Learn Programming with OCaml]]
- Nix 官方文档入口: [[https://nix.dev/][nix.dev]]
- Nix language basics: [[https://nix.dev/tutorials/nix-language.html][Nix language basics]]
- Nix flakes: [[https://nix.dev/concepts/flakes.html][Flakes]]
- nix develop 手册: [[https://nix.dev/manual/nix/stable/command-ref/new-cli/nix3-develop.html][nix develop]]
- Nixpkgs OCaml 文档: [[https://nixos.org/manual/nixpkgs/stable/#ocaml][OCaml in Nixpkgs]]

学习节奏建议：
- 每周 4 天学习 OCaml，每天 1.5 到 2 小时。
- 每周 1 天整理笔记。
- 每周 1 天完成练习代码、测试或小项目。
- 每周 0.5 到 1 天学习 Nix 相关内容，重点服务于当前 OCaml 学习环境。
- 每周允许 1 天缓冲。

每周固定动作：
1. 阅读 CS3110 对应章节。
2. 阅读 LPO 对应小节。
3. 在 ~nix develop~ 环境中使用 ~utop~ 手敲关键代码。
4. 用 ~dune~ 建一个小练习或维护已有练习。
5. 写一页 org 总结。
6. 提炼“这和 Python / Java / Lisp / Nix 有什么关系”。
7. 记录一个本周 Nix 问题，不追求一次性学深，但要把环境理解逐步补齐。

** 推荐 flake.nix

#+begin_src nix
{
  description = "CS3110 OCaml learning environment with Nix flakes";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
  };

  outputs = { self, nixpkgs }:
    let
      system = "x86_64-linux";
      pkgs = import nixpkgs { inherit system; };
      ocamlPackages = pkgs.ocaml-ng.ocamlPackages_5_3;
    in
    {
      devShells.${system}.default = pkgs.mkShell {
        packages = with ocamlPackages; [
          ocaml
          findlib
          dune_3
          utop
          odoc
          ounit2
          qcheck
          bisect_ppx
          menhir
          ocaml-lsp
          ocamlformat
        ];

        shellHook = ''
          echo "CS3110 OCaml environment"
          echo "OCaml: $(ocamlc -version)"
          echo "Try: utop"
        '';
      };
    };
}
#+end_src

若本机 nixpkgs 暂时没有 ~pkgs.ocaml-ng.ocamlPackages_5_3~，可以先改成：

#+begin_src nix
ocamlPackages = pkgs.ocamlPackages;
#+end_src
