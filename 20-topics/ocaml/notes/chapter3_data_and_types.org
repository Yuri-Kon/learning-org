* 为什么从列表开始？

教材开头给出了这样一句话：

#+begin_quote
An OCaml list is a sequence of values all of which have the same type.
#+end_quote

也就是说，一个 OCaml 列表是一系列具有相同类型的值。OCaml 列表使用单向列表实现。
