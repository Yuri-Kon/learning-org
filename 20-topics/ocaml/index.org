* OCaml 学习定位

学习 OCaml 不是为了短期求职使用 OCaml，而是通过一门偏函数式、强类型、带有成熟模块系统的语言，系统理解函数式编程思想，并反过来扩展我对其他语言的理解。

OCaml 在我这条路径中的作用：

1. 帮助我从命令式编程思维转向表达式式、类型驱动、数据建模驱动的思想
2. 帮助我理解不可变编程、递归、模式匹配、高阶函数、柯里化、代数数据类型
3. 帮助我理解模块、签名、抽象类型、函子等大型程序组织方式
4. 帮助我理解函数式数据结构、持久化、结构共享、尾递归、求值模型
5. 为之后学习 Lisp、Emacs Lisp、Scheme、Nix语言提供准备
6. 让Python / Java 中的函数式写法、不可变建模、类型抽象、组合式程序设计变得更自然

* 学习总目标
** 第一层：会写 OCaml
完成后应当能够：
- 使用 opam / dune / utop / ocaml-lsp-server 搭建项目
- 看懂 ~.ml~ / ~.mli~ / ~dune~ 等文件
- 使用 ~let~ / ~let in~ / ~function~ / ~match~ / ~type~ / ~module~ / ~module type~ / ~functor~
- 熟悉 ~list~ / ~array~ / ~option~ / ~result~ / ~record~ / ~variant~ / ~tuple~
- 能写递归、尾递归、 ~map~ / ~fliter~ / ~fold~ 风格程序
- 能写简单命令行程序
- 能用 dune 创建、编译、运行项目
- 能写简单单元测试
** 第二层：理解函数式编程思想
完成后应当能解释：
- 为什么函数式语言强调表达式
- 为什么不可变数据有助于推理
- 什么是递归和尾递归
- 什么是模式匹配，为什么它比 ~if-esls~ 更适合结构化数据
- 什么是代数数据类型
- 什么是高阶函数
- 什么是柯里化和部分应用
- 什么是 ~fold~ ，以及为什么 ~fold~ 可以表达很多递归模式
- 什么是持久化数据结构
- 什么是结构共享
- 什么是抽象类型、模块签名和函子
- 什么是类型推导
** 第三层：迁移到 Lisp / NixOS / Python / Java
完成后应当能够建立以下联系：
- OCaml 的 list / recursion / pattern matching 与 Lisp 的 list processing。
- OCaml 的 expression-oriented style 与 Nix 的表达式式配置。
- OCaml 的 immutability / persistence 与 Nix store、derivation、声明式配置。
- OCaml 的 module / signature / functor 与 Java interface / generic / package 的差异。
- OCaml 的 higher-order function 与 Python 中 map/filter/reduce、decorator、callback 的联系。
- OCaml 的 ADT 与 Java sealed class / enum / record 的联系。
- OCaml 的 type inference 与 Python 动态类型、Java 显式类型之间的差异。

* 每阶段检查问题

** Basics

- OCaml 中 if 为什么必须有统一的返回类型？
- let x = ... 和 let x = ... in ... 有什么区别？
- unit 类型有什么意义？
- 为什么函数调用不用括号？
- int 和 float 为什么使用不同运算符？

** Data and Types

- tuple 和 record 的差异是什么？
- variant 和 enum 的差异是什么？
- option 相比 null 的优势是什么？
- pattern matching 相比 if-else 的优势是什么？
- list 为什么天然适合递归？

** Higher-Order Programming

- 什么是一等函数？
- 什么是高阶函数？
- map / filter / fold 分别抽象了什么递归模式？
- fold_left 和 fold_right 的求值方向、栈使用有什么区别？
- 柯里化为什么有助于组合？

** Modular Programming

- module 和 compilation unit 的关系是什么？
- .mli 文件解决了什么问题？
- abstract type 的价值是什么？
- functor 和普通函数有什么相似与不同？
- OCaml 模块系统和 Java interface 有什么差异？

** Mutability

- ref 是什么？
- mutable field 和 ref 的关系是什么？
- array 和 list 的使用场景有什么不同？
- side effect 对程序推理有什么影响？
- 为什么函数式语言依然需要可变性？

** Persistence

- 什么是 persistent data structure？
- 什么是 sharing？
- 为什么向 list 头部添加元素是 O(1)？
- 为什么向 list 尾部添加元素通常要复制前面的结构？
- 回溯问题为什么适合持久化数据结构？

** Correctness

- specification 和 implementation 的关系是什么？
- black-box testing 和 glass-box testing 有什么区别？
- randomized testing 适合什么场景？
- 结构归纳为什么适合证明递归函数？
- 等式推理依赖什么前提？

** Interpreters

- AST 是什么？
- substitution model 如何解释变量？
- environment model 如何解释变量？
- type checking 和 type inference 有什么区别？
- 解释器学习如何帮助理解 Lisp / Nix？
