* 总体定位

本学习计划的核心目标是：以 OCaml 作为主要语言，系统理解函数式编程思想；以 Nix 作为学习环境和辅助对象，在配置 OCaml 工具链的过程中逐步理解 Nix 语言、flake、可复现开发环境与声明式依赖管理。

也就是说，本计划中两者的关系是：

- OCaml 是主要学习对象，用来学习函数式编程、类型系统、模块系统、递归、代数数据类型、解释器和程序正确性。
- Nix 是环境提供者，同时也是一个值得学习的函数式配置语言，用来管理 OCaml 学习环境，并帮助理解纯函数式、惰性求值、声明式构建和可复现性。
- 学习顺序上，不需要先把 Nix 学完再学 OCaml；更合适的方式是“边使用 Nix 提供环境，边在必要时理解 Nix 的语言和机制”。

* 学习原则

** 主线原则

1. 以 CS3110 为主线，优先保证 OCaml 语言本身的学习连续性。
2. 以 Learn Programming with OCaml 作为练习补充，用具体程序把 OCaml 写熟。
3. 以 Nix flake 管理本学习项目的环境，不优先使用全局安装或临时手动配置。
4. Nix 的学习采用“够用后深入”的方式：先会写 devShell，再理解属性集、函数、let、with、inherit、flake inputs/outputs、lock file。
5. 所有环境配置和练习代码尽量放入同一个仓库，形成可复现、可迁移、可回顾的学习项目。

** 环境原则

本项目不把 OCaml 工具链安装到系统全局作为主线，而是通过 ~nix develop~ 进入项目级开发环境。

这样做的好处：

- OCaml、Dune、utop、ocaml-lsp、ocamlformat 等工具由 ~flake.nix~ 统一声明。
- ~flake.lock~ 固定 nixpkgs 版本，便于将来复现环境。
- 不污染系统环境，退出 shell 后工具链不再暴露到普通 PATH。
- 可以在学习 OCaml 的同时自然接触 Nix 的函数式配置思想。

** OPAM 与 Nix 的关系

CS3110 官方安装页默认使用 OPAM 创建课程 switch。该路线适合严格跟随课程环境，也适合普通 OCaml 开发者。

本计划采用 Nix 作为主环境，因此：

- 初期不以 OPAM switch 为主线。
- 优先使用 Nixpkgs 中的 OCaml 包。
- 遇到 Nixpkgs 缺包、版本不匹配或需要严格复现 OPAM 生态时，再补充研究 ~opam-nix~ 或 Nix + OPAM 混合路线。
- 理解上可以把 OPAM 看作 OCaml 生态的包管理器，把 Nix 看作更外层的、跨语言的开发环境和构建环境管理工具。

** 推荐 flake.nix

说明：

- CS3110 当前安装页使用 OCaml 5.3.0。
- Nixpkgs 中可以通过 ~ocaml-ng.ocamlPackages_5_3~ 选择 OCaml 5.3 系列包集。
- 如果本机 nixpkgs 暂时没有该属性，可以先改成 ~pkgs.ocamlPackages~，优先保证学习环境跑通。

#+begin_src nix
{
  description = "CS3110 OCaml learning environment with Nix flakes";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
  };

  outputs = { self, nixpkgs }:
    let
      system = "x86_64-linux";
      pkgs = import nixpkgs { inherit system; };

      ocamlPackages = pkgs.ocaml-ng.ocamlPackages_5_3;
    in
    {
      devShells.${system}.default = pkgs.mkShell {
        packages = with ocamlPackages; [
          ocaml
          findlib
          dune_3
          utop
          odoc
          ounit2
          qcheck
          bisect_ppx
          menhir
          ocaml-lsp
          ocamlformat
        ];

        shellHook = ''
          echo "CS3110 OCaml environment"
          echo "OCaml: $(ocamlc -version)"
          echo "Try: utop"
        '';
      };
    };
}
#+end_src
