* 1. 使用说明

本文件用于记录每周要完成的学习任务。~index.org~ 负责说明总览、目标和阶段产出；本文件负责具体执行。

1. 代码：必须能编译、运行、测试。
2. 笔记：解释本周核心概念。
3. 复述：用 5 分钟说明本周解决了什么工程问题。

* 3. 第一周：C++ 模型基础与 Matrix 模块完善

** 3.1 本周目标

从“能写一个类”推进到“理解类、对象、引用、const、头文件、源文件、编译链接之间的关系”。

** 3.2 参考资料

1. C++ Core Guidelines：Interfaces、Resource management、Classes and class hierarchies。
2. cppreference：references、const、class、constructor、std::vector。
3. CMake Tutorial：基础构建、添加源文件、include directory。

** 3.3 每日任务

*** Day 1：复盘源码到可执行文件

学习内容：

1. 预处理、编译、汇编、链接的基本流程。
2. 每个 ~.cpp~ 是一个编译单元。
3. 头文件被 ~#include~ 后会被文本展开。
4. 链接阶段解决函数和对象符号。

项目任务：

1. 在 ~docs/how-form-executable.org~ 中写出项目从源码到可执行文件的流程。
2. 用一句话解释 ~main.cpp~ 如何调用 ~Matrix.cpp~ 中实现的函数。
3. 故意从 ~CMakeLists.txt~ 中删掉 ~cpp/Matrix.cpp~，观察链接错误，再恢复。

验收标准：

1. 能解释“声明能通过编译，定义缺失会在链接时报错”。
2. 能说清楚为什么新增 ~.cpp~ 后需要写进 ~add_executable~ 或库目标。

* 7. 第五周：Python 原型与 C++ 绑定

** 7.1 本周目标

建立 Python 与 C++ 的协作方式：Python 用于原型、测试、脚本化；C++ 用于核心计算。

** 7.2 核心任务

1. 用 Python 实现一份参考算法。
2. 用 pytest 验证 Python 版本输出。
3. 使用 pybind11 暴露 C++ Matrix 或算法函数。
4. 用 pytest 对比 Python 与 C++ 输出一致性。

** 7.3 每日安排

*** Day 1：Python 包结构

项目任务：整理 ~python/mini_wafer_engine/~，准备 pytest。

*** Day 2：Python 参考算法

项目任务：实现与 C++ 对应的均值、异常检测、连通区域统计。

*** Day 3：pybind11 最小模块

项目任务：暴露一个简单函数，例如 ~add(a, b)~，确认 Python 可以 import。

*** Day 4：暴露 C++ 算法

项目任务：暴露核心算法函数，处理基本类型转换。

*** Day 5：一致性测试

项目任务：pytest 读取同一 CSV，对比 Python 和 C++ 输出。

** 7.4 验收标准

1. Python 可以 import C++ 扩展模块。
2. Python 与 C++ 对同一输入输出一致。
3. 浮点数比较使用容差。
4. README 写明 Python 调用方式。
